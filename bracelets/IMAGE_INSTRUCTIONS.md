# Local Bracelet Images Setup

Place your 9 bracelet photos in the folder:

`bracelets/static/bracelets/images/`

Then update the file:

`bracelets/bracelet_image_map.txt`

Use the exact bracelet name on the left and the image filename on the right, for example:

`Amethyst Harmony | amethyst_harmony.jpg`

Extensions can be any browser-friendly image type, including `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`, `.bmp`, and `.svg`.

The current expected filenames are:
- `amethyst_harmony.jpg`
- `rose_quartz_glow.jpg`
- `citrine_sunrise.jpg`
- `labradorite_moon.jpg`
- `clear_quartz_clarity.jpg`
- `black_onyx_luxe.jpg`
- `moonstone_mist.jpg`
- `turquoise_dream.jpg`
- `jade_serenity.png`

After placing the files and saving `bracelet_image_map.txt`, refresh the browser. The site will show the local images on:

- `/bracelets/`
- `/bracelets/<id>/`

If you use different filenames, just update them in `bracelet_image_map.txt` to match.
